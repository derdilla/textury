# Contributing
This project is still in its early days and development is a bit more focused. There are still things you can do to help out

## Opening Bugs and Proposing Features

This is probably the easiest: Use the app and find what's wrong and what can be improved. There is no such thing as a wrong issue. Just make sure there is no existing one about the exact same topic. If you are unsure about something just create a new issue, the worst thing to happen is that it gets closed.

## Helping with the issue Tracker

If you find issues that are very similar or see other correlation and meta issues: feel free to leave a comment on any issue. You can also look at vague issues, or ones that aren't reproducible and try to write instructions on how to cause them.

## Contributing Code

We are still working out what it means to accept code contributions to an web app. There is a tension between our ability to provide an easy-to-use hosted version, and respecting contributors rights under an open source. If you have relevant legal expertise, and want to drive open contributions forward, feel free to open an issue or send us an email.

You can of course dig into the code in an open source fork.
